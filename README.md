# Лабораторна робота №3 — Angular

«Периферія» — навчальний каталог комп’ютерних аксесуарів із локальним REST API.

## Запуск

Потрібні Node.js 22.22.3+, 24.15+ або 26.x та npm. У каталозі проєкту виконайте `npm ci`. Далі запустіть у двох терміналах:

```bash
# Термінал 1
npm run api

# Термінал 2
npm start
```

Відкрийте [каталог](http://localhost:4200/products). Angular проксіює `/api` до локального JSON Server на порту 3000. Під час першого запуску API початкові записи з `db.seed.json` копіюються в `db.json`. Подальші зміни зберігаються в `db.json`.

## Перевірка

```bash
npm test -- --watch=false
npm run build
```
